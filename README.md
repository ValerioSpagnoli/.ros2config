# .ros2config

```
cd ~
git clone https://github.com/ArpsoftSpark/.ros2config.git
echo "source ~/.ros2config/ros2rc" >> ~/.$(basename $SHELL)rc 
source ~/.$(basename $SHELL)rc
```

## uros_installer
```
source ~/ros2config/uros_installer
uros_installer -i # to install Micro-ROS
uros_installer -u # to uninstall Micro-ROS
```
